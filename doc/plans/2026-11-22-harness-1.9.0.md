## Summary

1. Tasks: the state schema and field versions (1–2), `check --reader` (3–4), the template (5), the rule
   text (6–7), the release files (8), the full check and the PR (9).
2. Repo: pal-harness only. No project's pin changes, and Pal Center's dependency is not touched.
3. Approach: inline. One repo; two small Go changes and rule text.
4. Proof: `go vet ./...` and `go test ./...` (what `ci.yml` runs), with `go test -coverprofile` holding
   the 80% gate. Local runs set `GOFLAGS=-p=1 GOMEMLIMIT=2GiB`.
5. Each Go change is test first. The rule text is pinned by `TestHarness190Rules`, written red before the
   text. The version stays 1.8.0 until Task 8, so `TestCITemplateWiring` holds until then.
6. Risks: the phase skill is at 249 of its 250-line cap, so its edits are rewrites in place. The reader
   check depends on Pal Center's tags and `go.mod` path; a lookup that fails is logged and skipped by rule.

## Tasks

#### Task 1: the state tests (red)

- Files: `state/state_test.go`, `state/testdata/phase-state.yaml` (unchanged; cases are built from it).
- Test first: `TestPhaseStateOwnerStops`: a valid entry passes; each of these is a finding: a `kind` not
  in the waiting kinds, a zero `since` or `answered`, `answered` before `since`, a `via` not in
  `owner, approved, defaulted, changed, vetoed`, a `via` other than `owner` with `could_decide: false`;
  an unknown key inside an entry is an unknown-field finding that lists the allowed fields.
  `TestNewerFields`: a phase state with `qa` and `owner_stops` against reader 1.8.0 reports only
  `owner_stops` (1.9.0); against 1.6.0 reports both; against 1.9.0 none. A features file with a result
  `check:` against 1.6.0 reports `results.check` (1.8.0). `ParseVersion` accepts `1.8.0` and `v1.8.0`,
  refuses `1.8`, `x` and the empty string.
- Prove it: `go test ./state/` fails to compile or fails on the new tests.
- Commit: `Pin owner_stops and field versions in failing state tests`

#### Task 2: the state code

- Files: `state/state.go`.
- Code: `OwnerStop {Kind, Since, Answered, CouldDecide, Via}` and `PhaseState.OwnerStops`
  (`yaml:"owner_stops"`), validated in `ParsePhaseState`; `ViaValues`; the allowed-field hint covers
  `OwnerStop`. `FieldSince` maps `phase-state.qa` and `features.results.check` to 1.8.0 and
  `phase-state.owner_stops` to 1.9.0 (every unlisted field is 1.3.0). `ParseVersion` and
  `NewerFields(kind, b, reader)` walk the decoded YAML and return each listed field the file uses whose
  version is newer than the reader, sorted.
- Prove it: `go test ./state/` and `go vet ./...` pass.
- Commit: `Add owner_stops and the field-version table to the state package`
